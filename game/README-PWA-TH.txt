เปิดเล่น ติดตั้ง และออฟไลน์
เปิด URL HTTPS ของโครงการเดิม รอข้อความพร้อมเล่นออฟไลน์ก่อนตัดอินเทอร์เน็ต
ใช้เมนูติดตั้งแอป/เพิ่มไปหน้าจอหลักหากเบราว์เซอร์รองรับ ปุ่มติดตั้งขึ้นอยู่กับอุปกรณ์
ต้องตรวจ URL HTTPS หลังอัปโหลดและอุปกรณ์จริงอีกครั้ง การตรวจ viewport บน Windows ไม่ใช่ผลติดตั้ง Android หรือแท็บเล็ตจริง

อัปโหลดด้วย Cloudflare Pages Direct Upload
แตกชุด ZIP ที่ผู้ดูแลจัดทำแล้วเลือกโฟลเดอร์ที่มี index.html โดยตรง ให้ index.html อยู่รากเว็บ
คัดลอกไฟล์ครบทุกโฟลเดอร์ รวม recover-v166, recover-v164, _headers และ manifest.webmanifest
ไม่ต้องใช้คำสั่ง build หรือแพ็กเกจเพิ่ม หลังอัปโหลดตรวจเปิดซ้ำออนไลน์ โหลดใหม่ออฟไลน์ และเซฟบนโดเมนเดิม

จากหน้าเกมที่เปิดได้ รุ่นใหม่จะดาวน์โหลดรอไว้ก่อน ต้องจบรอบและรับรางวัลในทุกแท็บ แล้วกดเปิดรุ่นใหม่เอง
ขณะต่อสู้ พักรบ กำลังขึ้นรถ หรือยังไม่รับรางวัล จะไม่บังคับเปิดรุ่นใหม่ทับรอบ
ใช้เมนูสำรองเซฟส่งออก JSON ก่อนย้ายเครื่องหรือล้างข้อมูล เซฟจากไฟล์ local และ URL ต่างกันแยกกัน ไม่ซิงก์อัตโนมัติ
นำเข้าได้ก่อนเริ่มหรือหลังจบรอบและรับรางวัลแล้ว ตรวจตัวอย่างก่อนยืนยันแทนที่เซฟ
หากบันทึกถาวรไม่สำเร็จ ข้อมูลจากไฟล์จะไม่แทนที่เซฟหรือค่าหน้าจอ
ยังใช้ schema 2 และ key little-rescue-sideview-save-v2 เดิม ไม่ส่งออกสถานะต่อสู้ที่ยังไม่จบ
การโหลดใหม่หรือปิดรอบที่ยังไม่จบไม่คืนคุกกี้ดาวค่าเข้า

เกมและค่าตัวอย่างคงเดิม
ต้นแบบช่วยเพื่อนหนึ่งด่าน เลือกทีม 1–5 ตัว เล่น Manual หรือ Auto ไม่มีเงินจริง NFT wallet หรือการซื้อ
คุกกี้ดาวใช้เข้าด่านครั้งละ 3 ชิ้น ละอองใบไม้ใช้เรียกเพื่อนระหว่างต่อสู้ เป็นทรัพยากรคนละส่วน
ปืนฐานทั้งสองฝ่ายใช้ค่าตัวอย่างเท่ากัน: ระยะ 360 หน่วย ดาเมจ 12 ต่อกระสุน ยิงห่างกัน 4 วินาที
ปืนยิงเฉพาะตัวละครฝ่ายตรงข้ามในระยะ ไม่ยิงฐาน ไม่ยิงขณะพักหรือหลังจบการต่อสู้ ตัวเลขทั้งหมดเป็นค่าทดลองแก้ไขได้
ภาพและฟอนต์คงไบต์เดิมจากชุดที่อนุมัติ เก็บใบอนุญาต assets/fonts/OFL.txt ไปด้วย
