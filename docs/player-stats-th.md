# สถิติผู้เล่น (1.11.1)

เกมส่งสถิติแบบไม่ระบุตัวตนไปที่ `/api/stats` (Cloudflare Pages Function ใน `functions/api/stats.js`)
แล้วเก็บในฐานข้อมูล D1 ดูผลได้ที่ https://little-rescue.pages.dev/stats

## สิ่งที่เก็บ

- รหัสสุ่มของเครื่อง (สร้างในเครื่องผู้เล่น เก็บในคีย์ `little-rescue-stats-v1` ไม่เกี่ยวกับเซฟ)
- เปิดเกม, เริ่มด่าน, จบด่าน (ชนะ/แพ้, แพ้เพราะฐานแตกหรือหมดเวลา, เวลาที่ใช้, พลังที่เหลือ), ออกกลางด่าน, เวลาเล่นต่อครั้ง
- เวอร์ชันเกม, จำนวนด่านที่ผ่านแล้ว, เปิดจากไอคอนแอปหรือไม่

ไม่เก็บชื่อ, เซฟ, IP หรือข้อมูลส่วนตัว ผู้เล่นปิดได้ในเมนู "ติดตั้ง อัปเดต และสำรองเซฟ"
ถ้าออฟไลน์หรือ endpoint ยังไม่พร้อม เกมจะทิ้งข้อมูลเงียบๆ ไม่มีผลกับการเล่น

## ตั้งค่าใน Cloudflare (ทำครั้งเดียว)

1. Cloudflare dashboard → **Storage & databases → D1 SQL database → Create** ตั้งชื่อ `little-rescue-stats` แล้วกด Create
2. **Workers & Pages → little-rescue → Settings → Bindings → Add → D1 database**
   ชื่อตัวแปร (Variable name) `DB` เลือกฐานข้อมูล `little-rescue-stats` → Save (ทำในแท็บ Production)
3. หน้าเดียวกัน **Variables and secrets → Add** เลือกชนิด **Secret** ชื่อ `STATS_KEY`
   ค่าเป็นรหัสยาวๆ ที่จำได้ (ใช้เปิดหน้าสถิติ) → Save
4. ค่าใหม่จะใช้ได้หลัง deploy ครั้งถัดไป (merge PR เข้า main ก็ deploy ให้เอง) ตารางในฐานข้อมูลสร้างเองตอนมีข้อมูลแรก
5. เปิด https://little-rescue.pages.dev/stats ใส่รหัส `STATS_KEY` แล้วกด "ดูสถิติ"

ไม่บังคับ: **Workers & Pages → little-rescue → Metrics → Web Analytics → Enable** จะได้ยอดคนเปิดหน้าเว็บ
ประเทศ และอุปกรณ์ ฟรีและไม่ใช้คุกกี้

ลิงก์ทดสอบ (pr-N.little-rescue.pages.dev) ถูกแยกเป็น "ลิงก์ทดสอบ" ในหน้าสถิติ ถ้าอยากให้ลิงก์ทดสอบเก็บด้วย
ให้เพิ่ม binding `DB` และ `STATS_KEY` ในแท็บ Preview ด้วย ถ้าเกมมีโดเมนของตัวเองในอนาคต ให้เพิ่มตัวแปร
`PROD_HOSTS` เช่น `little-rescue.pages.dev,game.example.com`

## อ่านผล

- **แต่ละด่าน**: อัตราชนะต่ำ + "เหลือพลังศัตรูตอนแพ้" น้อย = เกือบชนะ ลดความยากนิดเดียวก็พอ ถ้าเหลือมาก = ยากเกินไป
- **ผู้เล่นหยุดอยู่ที่ไหน**: ผู้เล่นที่ไม่เข้าเกม 3 วันขึ้นไปนับว่าเลิกเล่น ดูว่าติดด่านไหนมากที่สุด
- **D1 / D7**: ผู้เล่นใหม่ที่กลับมาเล่นวันถัดไป / วันที่ 7

ฟรีของ D1: เขียน 100,000 แถวต่อวัน (ผู้เล่นหนึ่งคนใช้ราว 10–40 แถวต่อวัน) พอสำหรับหลักพันคนต่อวัน
